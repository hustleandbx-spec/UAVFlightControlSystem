## 2. 生命周期备注

- 状态词表 = { 跟踪中 / 已触发 / 已缓解 / 已接受 / 已闭环 }（process/00 §4）。
- 新增风险登记规则：ID 顺延 R-07...；处置须四选一（缓解/接受/后置）+ 记录理由。
- 假设被推翻候选 / 长期悬置 TBD → 依 process/00 §3 转化规则入册。
