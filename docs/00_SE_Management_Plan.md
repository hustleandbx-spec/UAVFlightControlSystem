## 1. 目的、范围与体系总览

本文件是 FlightCore 项目 SE 体系的**宪法（宪法层）**：登记文档树与各文档状态（§3）、声明采用的标准与映射（§2）、固化配置管理与变更纪律（§5）、登记术语与编号体系（§4）。它**不做**需求内容承载（需求在 `product/` 各层文档），**不做**逐层评审清单（开发前门禁清单 = 会话·决策日志 §12 SE 链矩阵，过签记录 = `process/04`）。

**体系 = 宪法层 + 两条链 + 合规轨：**

| 链 | 位置 | 回答 | 内容 |
|---|---|---|---|
| 宪法层 | 本文件（00） | 体系怎么组织 | 文档树 / 标准映射 / 术语编号 / 配置 / 工具链 / 门禁声明 |
| 产品与技术链 | `product/`（01..15） | 做什么、做成什么样、怎么验证 | 需求 / 设计 / 接口 / V&V |
| 过程管理链 | `process/`（00..04） | 怎么定、怎么管、出过什么问题、门过了没有 | 决策 / 风险 / 变更 / 问题 / 评审 |
| 合规/适航轨 | 显式后置 | 法规合规 | TBD-002，非 SE 文档 |

本文件保持最小、稳定，只随文档树、标准映射与术语/编号体系变化而修订。过程管理链的具体规则见 `process/00_Process_Management.md`。

### 2.3 DAL 与工具鉴定适用性（预留框架，DEC-123）

> DEC-123（2026-08-12）：第一阶段纯 MIL/SIL 仿真、无实机（DEC-033/114），适航/合规轨 TBD-002 显式后置；DAL 分配与工具鉴定（DO-330）属合规行为，**不写死"不适用"**——过早定死会锁死未来合规路径。本节只建适用性框架 + 理由链，结论标"TBD-002 时回填"。

| 项目 | 适用性框架 | 结论 | 回填时机 |
|---|---|---|---|
| DAL 分配（DO-178C/DO-331 按等级） | 无实机、无审定目标 → DAL 是否分配及等级 | **TBD-002 时回填** | 适航轨打开 |
| 工具鉴定（DO-330） | 工具（MATLAB/Simulink/Simulink Test）角色 = 开发/验证辅助 vs 消除·压制验证活动 | **TBD-002 时回填**（当前倾向：验证输出人工复核 DEC-120、判据独立于工具 → 不触发；待复核） | 适航轨打开 |
| DO-331 目标级适用性 | MB.6.3/.4/.7/.8 逐条（§2.2 表） | ✅ 已定稿（开发过程保证，不受 DAL 决策影响） | — |

**理由链**：① 第一阶段交付 = MIL/SIL 仿真（DEC-033/114）⇒ 无实机 ⇒ 无审定目标 ⇒ DAL 无分配依据；② 工具鉴定触发条件（消除/压制验证输出且无独立核验）在第一阶段验证设计中不满足（关键输出人工复核，DEC-120；判据独立于工具）；③ 以上支撑"当前倾向"，但结论仍回填 TBD-002（合规轨正交，DEC-033/115），避免锁死未来合规选项。
