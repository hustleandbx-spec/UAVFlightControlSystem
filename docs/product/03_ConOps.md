## 1. 系统角色与边界（DEC-005）

- **GCS（地面站）**：负责任务规划——航点/动作/偏航/载荷朝向/传感器/拍摄数量；任务计划语义校验权威在 GCS 规划层。
- **FlightCore**：场景无关的执行者。任务场景（语义层）FC 不关心；物理场景（环境层）经感知（未来模块）作为约束输入。
- **操作者**：受过培训的设备操作人员（DEC-003）——对安全操作和应急处置有清晰认识，不关心/不需要了解内部算法实现，非飞控开发人员。

## 2. 决策权威模型（DEC-004）

异常出现 → **立即告警**；操作者指令在**安全包线内**执行，不安全则**拒绝并说明**；无指令时按 GCS 配置默认行为执行（悬停/返航/继续任务，可配置）。**安全约束 > 操作者指令**。"依据指令进行" = "依据指令在安全约束内进行"。

## 3. 任务运行流程（五段，DEC-035..040）

正常任务 = 单条完整航线（出航+任务+返航一次编入计划，DEC-099），FC **单序列执行**，命令集无"任务"指令。飞行流程分五段：

| 段 | 内容 | 关键判据 |
|---|---|---|
| ① 起飞 | 起飞门通过 + 操作者"开始任务"确认 → 自主离地 → **原地爬升**至安全起飞高度 | 达到安全起飞高度 = 起飞段完成（DEC-045） |
| ② 出航 | 安全高度 → 飞向任务首航点（默认直线，可含 GCS 绕行航点） | 计划为主（DEC-035） |
| ③ 任务 | 沿航点序列执行（停/过）；"停"点到达判据 + 动作驱动停留；"过"点曲线穿越 | 到达判据（DEC-055/094/095） |
| ④ 返航 | 末航点（停）完成 → 爬升 H_rtl → 水平飞回 home 上方 | 末航点停语义（DEC-048/096） |
| ⑤ 降落 | home 上方垂直下降、近地减速、触地（多判据 AND+时间保持） | 触地检测（DEC-100）；触地后停转+加锁+上报（DEC-042） |

**阶段切换判据 = 计划为主**（禁出区仅辅助安全判定，非第一判据，DEC-025）。**五段 = 人为划分的过程视图，非实现状态机**（DEC-067）——实现中进度由计划位置派生。

## 4. 运行模式

| 模式 | 说明 |
|---|---|
| **全自主任务** | 正常任务全程自主飞行（起飞→出航→任务→返航→降落），操作者只监督（DEC-019）。MOE-C 测量区间 = "开始任务"确认后 → 降落触地完成，介入计数对象 = {接管, 异常指令}（"开始任务"不计入，DEC-079） |
| **人工接管** | 操作者可在任意阶段（含降落段）接管控制；指令在安全约束内执行，越界拒绝并说明（DEC-023/011）。降落段接管的物理限制留给设计层 |
| **模式级命令** | 飞行中收到返航/降落/悬停 → **立即中止计划 + 当前位置执行**（DEC-101）：返航 = 当前位置生成默认返航（爬升 H_rtl→home→降落）；降落 = 当前位置触发垂直剖面；悬停 = 当前位置悬停保持 |
| **临时上传航点** | 飞行中"直接导航到点 P"= 独立 go-to-point：数据阶段（存储+校验）+ 激活阶段（Commander 审查批准 → 中断计划导航到 P 悬停），不触碰计划槽（DEC-071/102）。"继续/Resume"命令接口已定义、实现后置（DEC-037） |

## 5. 操作者交互点（DEC-019/032）

- HMI 交互点 = **{开始任务, 接管, 异常指令}**，无逐阶段确认（起飞/航线/降落全自动）。
- **起飞触发 = 操作者最终确认制**（DEC-043）：起飞门 7 条全满足是"允许起飞"必要条件，但不触发离地；"开始任务"确认是离地前最后一道指令。**门持续有效制**（DEC-044）：确认后至实际离地前，起飞门须持续满足，任一失效 → 不得离地 + aborted 上报。
- **监督**：第一阶段接受 BVLOS（超视距），操作者监督依赖遥测/视频（DEC-032）。
- **告警/处置**：异常 → 立即告警 + 配置默认行为（DEC-004）；告警策略细节属异常工作包（后置，TBD-003）。

## 6. 环境与运行条件（摘要）

见 05_ODD_and_Environment：户外/日间/小雨；温度 -20~50°C；风 ≤12 m/s（起降 8）；GNSS/RTK 可用（RTK fix 为起飞硬门）；平地区域；BVLOS 可接受。感知型约束（避障/地形跟随）第一阶段不启用（DEC-006）。

## 7. 任务与系统目标关系

参考架次 = 电力设施巡检（见 04_Reference_Missions）。成功判据 = 自动完成整个航线任务 + 全程安全包线内 + 预设动作完整执行。效能度量见 06_MOE_MOP_TPM（MOE-A 任务完成度第一优先；安全门一票否决）。
