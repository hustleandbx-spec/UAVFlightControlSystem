## 1. 系统需求

| ID | 需求 | 来源 | 验证方法 |
|---|---|---|---|
| SYS-REQ-001 | 系统应能在执行任务前加载并校验任务计划；解析/结构校验不通过（字段/命令非法、容量超限、末航点非停、段结构非法）时拒绝执行该计划并通知操作者；计划语义有效性（包线内、禁飞区外）由 GCS 规划层保证 | DEC-016, DEC-020, MOE-A, DEC-092 | VER-001：注入不可解析/结构非法计划，验证拒绝+通知；越包线计划验证执行链限幅兜底（非拒绝） |
| SYS-REQ-002 | 起飞前系统应确认任务计划已校验通过 | DEC-020, DEC-016 | VER-002 |
| SYS-REQ-003 | 起飞前系统应确认 GNSS/RTK 定位与定向有效 | DEC-020, ODD | VER-003 |
| SYS-REQ-004 | 起飞前系统应确认使用中的传感器健康 | DEC-020 | VER-004 |

| SYS-REQ-006 | 起飞前系统应确认地理围栏/任务区域配置有效 | DEC-020, DEC-006 | VER-006 |
| SYS-REQ-007 | 起飞前系统应确认动力系统就绪 | DEC-020 | VER-007 |
| SYS-REQ-008 | 起飞前系统应确认与地面站链路接通 | DEC-020 | VER-008 |
| SYS-REQ-009 | 当且仅当 SYS-REQ-002..008 全部满足时，系统才允许起飞 | DEC-020 | VER-009 |
| SYS-REQ-010 | 系统应能自主执行任务计划中的航点序列，完成起飞、出航、任务区、返航、降落全流程，无需操作者逐阶段操作 | SYS-GOAL-01, DEC-019, MOE-A | VER-010：参考架次完整执行，按 MOE-A 判定 |
| SYS-REQ-011 | 系统应允许操作者在任意阶段（含降落段）介入控制——介入方式包括远程下发模式级命令（返航/降落/悬停，FC 自主执行并立即中止当前计划）与直接接管飞行控制（人工握杆）；介入指令应在安全约束内执行，"越界"=违反安全约束硬限（包线/禁飞区/能源等，DEC-028）或当前状态不允许（未解锁/阶段非法）；越界拒绝并说明，安全硬限优先于命令审查（DEC-004/059）；降落段接管物理限制属设计层（DEC-023） | DEC-003, DEC-004, DEC-019, DEC-023, DEC-028, DEC-059, DEC-079, DEC-101, DEC-110, MOE-C | VER-011：各阶段（含降落段）注入远程模式命令与人工接管，验证执行/接管与越界拒绝说明 |
| SYS-REQ-012 | 检测到异常立即告警；操作者指令优先于配置默认；无指令时按配置默认执行；处置均在安全约束内【实现后置】 | DEC-004, MOE-C | VER-012：注入异常，验证告警/默认/覆盖 |
| SYS-REQ-013 | 能源不足时系统应中断任务、保存任务进度、按配置默认处置【实现后置】 | SYS-GOAL-06, DEC-004 | VER-013：模拟能源不足场景 |
| SYS-REQ-014 | 系统应在起飞门全部满足且操作者确认（"开始任务"）后，自主离地并爬升至安全起飞高度 | DEC-019, DEC-035, DEC-043, DEC-044, SYS-REQ-009 | VER-014：仿真起飞门通过→操作者确认→离地→爬升到安全高度 |
| SYS-REQ-014a | 操作者确认"开始任务"后至实际离地前，起飞门应持续有效；任一失效时系统不得离地，并上报命令结果 aborted——本需求整体为异常处置、**实现后置**（DEC-091/111，第一阶段不含异常处置内容；正常流仅"开始任务"命令审查一次性门检查，SYS-REQ-002..009/009） | DEC-020, DEC-043, DEC-044, DEC-091, DEC-111 | VER-014a：确认后注入门失效 → 不得离地 + aborted（异常工作包验证，第一阶段后置） |
| SYS-REQ-015 | 系统应达到安全起飞高度后，自主沿出航路径飞向任务首航点；出航路径默认由起飞点至首航点的直线构成，可由 GCS 预规划绕行航点扩展（直线穿越禁飞区时）。出航段高度由航点序列定义，系统不施加全局最低高度约束 | DEC-035, DEC-036, DEC-045, MOE-A | VER-015：仿真注入含绕行出航路径的计划，验证按路径执行且不穿越禁飞区 |
| SYS-REQ-016 | 系统全程（出航/任务/返航）不得进入禁飞区 | DEC-025, DEC-036, DEC-039, DEC-092 | VER-016：第一阶段保障 = GCS 规划层保证（规划不生成穿越航线）+ FC 围栏数据装载有效性（SYS-REQ-006 起飞门）；FC 不做计划侧禁飞区静态校验；动态越界强制见 §2 安全约束集（实现后置） |
| SYS-REQ-017 | 系统应按任务计划中的航点序列执行任务段："停"点在满足到达判据（位置/高度/偏航/速度门限，连续 N 个评估周期均满足，N 值控制分析产出；数值属 MOP/TBD-009）后停留至该航点任务动作执行完成（第一阶段动作序列为空 → 到达即推进）再推进至下一航点；"过"点为曲线轨迹约束点，系统沿曲线轨迹穿越、不要求逐点精确到达，曲线段结束于下一"停"点 | DEC-007, DEC-038, DEC-046, DEC-094/095, TBD-009, MOE-A/B | VER-017：参考架次航点序列执行，日志比对按序推进与停/过行为 |
| SYS-REQ-018 | 系统应按航点定义的偏航模式（固定航向 / 跟随航线）与参数执行偏航 | DEC-007, DEC-047 | VER-018：注入含偏航模式与参数的航点，验证偏航执行符合参数 |
| SYS-REQ-019 | 系统应在任务末航点（按"停"语义、以到达判据判定完成）完成后，自主进入返航段飞回 home 降落点，返航路径避开禁飞区 | DEC-039, DEC-025, DEC-048 | VER-019：参考架次末航点后验证返航至 home |
| SYS-REQ-020 | 系统到达 home 点上方后，应自主垂直下降、近地减速并着陆（降落剖面由系统自动生成，受包线约束，数值归 Vehicle Definition） | DEC-035, DEC-040, DEC-049 | VER-020：仿真验证下降-减速-触地流程 |
| SYS-REQ-021 | 系统应通过多判据 AND + 时间保持组合（垂向速度 / 旋翼卸载 / 无水平运动 / 无旋转 + 高度门限 + 指令下降无运动强判据，数值 TBD）可靠判定触地；触地成功后电机停转、加锁并上报任务结束 | DEC-041, DEC-042, DEC-050, DEC-100 | VER-021：仿真触地场景验证正向判定与终止行为；含异常信号的假阳性抑制场景归异常工作包（TBD-003） |
| SYS-REQ-022 | 系统应在控制分析为满足轨迹跟踪/抗风 MOP、协调传感器速率、支撑安全逻辑与操作者指令响应所确定的控制周期与延迟内完成状态估计、控制计算、安全监视与指令执行（数值由控制分析产出，不在此填数） | DEC-056 | VER-022：控制分析文档评审 + SIL 时序仿真验证周期/延迟符合分析值 |

**开放项（后续访谈填充）：** 出航/任务区/降落的具体要求、MOP 数值、安全起飞高度值（配置参数）、降落完成判据（触地检测）、安全包线定义与数值。
