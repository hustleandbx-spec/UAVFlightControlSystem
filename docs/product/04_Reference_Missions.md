## 1. 任务对象

**电力设施巡检**：

- **带状** = 输电线路走廊；
- **片状** = 变电站场区。

## 2. 任务参数（第一版，候选）

| 项 | 值 | 来源 |
|---|---|---|
| 出航距离 | 起飞点到任务区 ≤ **1 km** | DEC-010 |
| 任务区形态 | 带状 + 片状 | DEC-010 |
| 作业高度 | 典型 ≈ **输电塔高度**；上限 = **真高 1000 m**（包线上限，极少使用） | DEC-010/011 |
| 架次时长 | **30 min**（任务区主导型架次） | DEC-010 |
| 第一阶段限制 | **平地区域**（地形起伏任务后置） | DEC-015 |

## 3. 成功判据（DEC-010）

参考架次成功判据 = 自动完成整个航线任务 **且** 全程安全包线内 **且** 预设动作完整执行。

## 4. 长期 Reference Mission（定义系统目的，暂不实现）

工业巡检 + **三轴光电吊舱**（DEC-009，未来载荷参考）。

> 说明：第一阶段无载荷（DEC-009），第一阶段 MOE 为"飞行执行代理"；真实任务 MOE（数据覆盖/缺陷识别）随载荷后置。参考架次同时作为 MOP 数值推导的输入（DEC-010 → MOP → 实时性分析）。
