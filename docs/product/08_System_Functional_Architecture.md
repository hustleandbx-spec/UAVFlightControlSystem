## 1. 系统边界（DEC-005）

- **GCS** = 任务规划层（航点/动作/偏航/载荷朝向/传感器/拍摄数量），负责任务语义与规划。
- **FlightCore** = 场景无关的执行者；任务场景（语义层）FC 不关心；物理场景（环境层）经感知（未来模块）作为约束输入 FC Safety 层。
- **感知** = 未来演进（DEC-006，第一阶段仅非感知型约束）。

## 2. 模块集及职责（DEC-057..069/104）

| 模块 | 功能定位 | 对应（会话·决策日志） |
|---|---|---|
| Commander | 顶层命令模块：**武装状态（加锁/解锁）+ 命令审查门卫**（校验当前状态能否执行命令，通过才下发）；统一 GCS 命令入口 + 路由；**不持有任务五阶段状态** | DEC-058/059/066；SYS-REQ-009/011/014/014a |
| MissionManager | 任务管理：**任务语义唯一权威**，持有任务进度（由计划位置派生的标签），计划接收/校验/存储/段切分/逐段推进，下发运动学合同给 Navigator | DEC-061/092..102；SYS-REQ-001/017/019 |
| Navigator（制导） | **统一轨迹生成器**：所有运动参考轨迹（航线段 / 起飞爬升 / 默认返航 / 降落剖面）；不解析任务语义，只执行运动学合同，产出 {位置,速度,偏航} 参考流 | DEC-061/062/063/104；= Vision Guidance |
| FlightControl | 控制律：闭环跟踪轨迹参考（速度→姿态→内环）；内部含混合器子功能（数据解耦，DEC-064） | DEC-063/064；轨迹跟踪 MOP |
| StateEstimation | 状态估计：位置/速度/姿态/角速度/高度估计（输入 RTK/IMU/气压 + 传感器扩展口子） | 导航 MOP；DEC-105 |
| Gateway | 通信：纯传输层（MAVLink 帧收发/遥测流/命令收帧/计划文件上传 FTP），**不做语义解析** | DEC-069 |
| Logging | 日志/诊断：独立横切模块，订阅各模块数据落盘、异常事件记录、诊断查询应答 | DEC-069 |

| 参数系统 | 运行时参数/配置管理；**后置（TBD-015）** | DEC-074 |

## 3. 关键职责分工（DEC-057..062）

- **安全约束 = 横切直接否决层（DEC-057）**：非平行功能模块，任何安全约束触发时直接否决/压低任务推进、制导、控制链输出，不经接口协商。
- **命令审查 ≠ 安全否决（DEC-059）**：命令审查 = 程序/状态合法性（武装、起飞门汇总），属 Commander；安全否决 = FailSafe 模块事件式应急（断链→悬停/迫降），横切。
- **Commander 状态视图 = 模块权威 + 只读镜像（DEC-060）**：各模块（MM/Navigator/SE/...）为各自状态权威生产源，向 Commander 回报；Commander 只能读、不能改；单一权威、无双源。FailSafe = Commander 下级模块。
- **MissionManager = 任务语义唯一权威（DEC-061）**：航点/航线/停过/到达判据/阶段均由 MM 持有与管理；Navigator 不解析任何任务语义。
- **Navigator = 运动学合同执行器，判据无感知（DEC-062）**：合同只含位置 + 设计终止状态（0.1m/速度归零），**不含到达判据阈值**；到达判据评估 + 段推进 = MM；Navigator 判据完全无感知。
- **混合器 = FlightControl 内部子功能，规则十二 = 数据解耦（DEC-064）**：不设独立 Mixer 模块；混合器矩阵参数来自 Vehicle Definition；内部按"虚拟控制量 {F, Mx, My, Mz} → 分配 → 电机指令"组织，为未来构型留提取点。
- **Navigator = 统一轨迹生成器（DEC-104）**：航线段（合同→轨迹）、起飞爬升（DEC-107）、默认返航（爬升 H_rtl → home，DEC-096）、降落剖面（垂直下降+近地减速，DEC-049）均 Navigator 生成；MM 只触发意图、FC 只跟踪。

## 4. 数据流与依赖（DEC-070/071/064）

- **航线 = 数据通道 → MissionManager**；**命令/查询 = 指令通道 → Commander**（Gateway 按数据 vs 指令分两条路径，DEC-070）。
- **临时上传航点 = 外部单步、内部两步（DEC-071）**：数据阶段（新点经数据通道 → MM 存储+校验）+ 激活阶段（指令通道 → Commander 审查批准 → MM 执行）；客户端不感知内部两阶段。
- **执行链主环（DEC-064/085/086）**：Commander→（模式命令）→MM→（运动学合同）→Navigator→（{位置,速度,偏航} 参考）→FC→（内部混合器）→电机指令。

## 5. 五阶段模型 = 人为划分的过程视图（DEC-067）

飞行五段（起飞/出航/任务/返航/降落）是**人为划分的标签/过程视图**，**不是驱动程序的独立状态机**。实现中 MM 的执行进度 = 由计划位置派生的**进度标签**（当前航点/末航点/是否返航/降落）；包线/速度差异不读阶段，读**航点参数** + Vehicle Definition/任务配置（起降段数值）。
